# Seed directories — one per line:   COUNTRYCODE  URL
#
# Run:  node daemon.js        (or let the hourly Scheduled Task do it)
# Lines starting with # are ignored.
#
# COUNTRYCODE is an ISO code, or AUTO for a directory that spans countries.
# With AUTO each club's country is taken from its own domain, and a club on
# a .com — which says nothing about where it is — is skipped rather than
# filed under a guess. Language is a required field, so a guess is worse
# than an omission.
#
# Before adding anything here, check it:
#
#     node check.js <url> [COUNTRY] --detail
#
# That fetches the page the way the daemon does — same character sets, same
# robots.txt rules — and prints how many club links and emails are actually
# in the HTML. A directory that looks rich in a browser is often empty to a
# crawler because the list is drawn by JavaScript. Every check is recorded
# in data/checked.log, so nothing is investigated twice.
#

# Curlie open directory (curlie.org)
#   Looked like the best find of the lot: a curated regional tree of tennis
#   and squash club listings, and its squash index alone holds 78 links
#   straight to club websites. It cannot be used.
#   - robots.txt asks for "Crawl-delay: 1000". Read literally that is one
#     page every seventeen minutes, so a 600-page walk would take a week.
#   - After a couple of hundred requests the site starts answering 200 OK
#     with a zero-byte body. Not an error, not a 429 — just nothing. A
#     crawler reads that as "this page has no clubs on it" and moves on,
#     which is how a first walk recorded 122 of 220 pages as dead.
#   The site also sends no Content-Type header at all, which is worth
#   knowing: the fetcher used to require one and threw away every page.
#   discover.js still exists and works, but there is no polite way to run it
#   against Curlie at any useful rate.
#
# Playtomic directory (directory.playtomic.io)
#   The obvious first choice for padel — Spain, Portugal and Latin America
#   in one place. robots.txt disallows automated access, and the daemon
#   honours robots.txt, so it would fetch nothing. Left out deliberately.
#
# Tennis Australia club finder (tennis.com.au/.../clubs)
#   Returns nothing to a plain request. The club list is drawn by
#   JavaScript, so it is not in the HTML at all.
#
# England Squash finder (englandsquash.com/finder)
#   Over 700 clubs, and the club pages have tidy enumerable URLs —
#   /finder/club/<slug>/<id> — which looked very promising.
#   Opened it in a real browser to find the search endpoint behind the
#   JavaScript. The site runs Cloudflare's bot challenge: the finder issues
#   a cdn-cgi/challenge-platform request on load, and a plain fetch of a
#   club page returns nothing at all. There is no automated way in that
#   respects how the site is set up. Not a JSON-endpoint problem — a
#   deliberate closed door.
#
# Portuguese Tennis Federation (tenis.pt / fptenis.pt)
#   Around 300 affiliated clubs across 13 regional associations, but no
#   crawlable listing page — the club data sits behind the TieSports
#   platform. The 13 regional associations publish their own lists; those
#   are the pages worth finding.
#
# Federação Portuguesa de Padel (fppadel.pt)
#   Club data is on tiepadel.com behind a federated-member area.
#
# Cheshire Squash find-a-court
#   Only 7 outbound club links, and several point at web.archive.org
#   snapshots rather than the clubs.
#
# US Court Tennis Association international list
#   40 emails on one page, which is tempting, but the names are not linked,
#   so there is nothing for the crawler to pair an address with. It is also
#   real tennis rather than the three sports asked for.
#
# Scraper resale sites (rentechdigital and similar)
#   They do list clubs with emails, but the addresses are masked on the
#   public page and only unlocked on payment. Nothing to read.
#
# Modern federation club finders — all the same story
#   Checked and empty to a crawler, because the list is drawn by JavaScript
#   after the page loads. The HTML that arrives has no club in it:
#     fctennis.cat/clubs/            Catalan tennis
#     fap.es/clubes                  Andalusian padel
#     padelfederacion.es/Clubes      Spanish padel
#     ulstertennis.co.uk/category/clubs
#     leinstertennis.ie
#   This is now the normal shape for a federation site, and it is why RFET
#   is so valuable: it is old enough to be plain HTML.
#
#   These are not lost causes, they just need a different move. Open one in
#   a browser, watch the network tab while the list loads, and find the JSON
#   request behind it. That URL is plain HTTP and the daemon can read it —
#   but it needs a JSON reader, which does not exist yet. Worth building
#   when there is time: it is the difference between Spain and everywhere.
#
# Racketeer, the deeper pages
#   England.html and its siblings are navigation, not lists — one link each,
#   to clubs.html, which is navigation again. The actual club links are
#   somewhere below that and were not found. Left seeded because the pages
#   are tiny and cost nothing to re-read, but do not expect much.


# ===========================================================================
# WHERE THE REST COMES FROM
# ===========================================================================
#
# Federation directories only exist where there is a federation with a
# crawlable website. That covers Spain, the UK, Ireland and a handful of
# others, and leaves most of the eighty-three countries in the brief with
# nothing at all — there is no Tuvalu tennis directory to walk.
#
# OpenStreetMap fills that gap, and it is where the breadth comes from:
#
#     node lib/osm.js --all        every country, in priority order
#     node lib/osm.js --status     what has been imported
#
# It keeps the places that publish a website or an email; the rest are
# recorded in data/osm-leads.json as named clubs with no contact yet, so
# they are not rediscovered on every run.
#
# The daemon also does one country per round on its own, so coverage
# advances without anyone asking.
#
# Searches that find more of the crawlable kind, if you want to add seeds:
#
#   Spain, beyond the national body — the 17 regional federations list more
#   clubs than RFET does, and they cover padel, which RFET does not:
#     "federación de padel" <region> clubes
#     federació catalana de tennis clubs
#
#   Portugal — the 13 regional tennis associations:
#     "associação de ténis de" <district> clubes filiados
#
#   Latin America:
#     "asociación de padel" <country> clubes afiliados
#     federación de tenis <country> clubes
#
#   Brazil:
#     "federação de tênis" <state> clubes filiados
#
#   Squash, thin everywhere — go at it federation by federation:
#     squash <country> federation club list
#
# League and competition sites are underrated. A divisional fixture list is
# a list of clubs with a secretary's email printed beside each one.
