# Spain, beyond the national body — the 17 regional federations list more
# clubs than RFET does, and they cover padel, which RFET does not:
#   "federación de padel" + <region> + clubes
#   federació catalana de tennis clubs
#   federación andaluza de padel clubes
#
# Portugal — the 13 regional tennis associations:
#   "associação de ténis de" <district> clubes filiados
#   federação portuguesa padel clubes
#
# Argentina, Mexico, Chile, Colombia, Peru, Uruguay:
#   "asociación de padel" <country> clubes afiliados
#   federación de tenis <country> clubes
#
# Brazil:
#   "federação de tênis" <state> clubes filiados
#   confederação brasileira de tênis clubes
#
# Squash, which is thin in all the above — go at it by federation:
#   england squash club finder
#   squash <country> federation club list
#
# UK and Ireland, current rather than 2019:
#   lta venue finder / tennis ireland affiliated clubs
#   <county> tennis league clubs contacts
#
# Australia, New Zealand, South Africa, India:
#   tennis <state> affiliated clubs list
#   squash <state> clubs directory
